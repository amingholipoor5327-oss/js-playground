# پروژه منوی رستوران

یک منوی ساده و زیبا برای رستوران با استفاده از HTML و CSS خالص

## 🚀 ویژگی‌ها

- طراحی ساده و تمیز
- واکنشگرا (Responsive) - مناسب برای موبایل و دسکتاپ
- بدون نیاز به کتابخانه یا فریمورک اضافی
- کدهای تمیز و قابل فهم

 
## 🎨 طراحی

### رنگ‌های استفاده شده:
- قهوه‌ای تیره: `#8B4513` (برای عنوان‌ها)
- قهوه‌ای روشن: `#D2691E` (برای قیمت‌ها)
- سفید: `#FFFFFF` (پس‌زمینه منو)
- خاکستری روشن: `#f5f5f5` (پس‌زمینه صفحه)

### فونت:
- فونت پیش‌فرض سیستم (Arial, sans-serif)

## 📱 سازگاری

- مرورگرهای مدرن (Chrome, Firefox, Safari, Edge)
- دستگاه‌های موبایل (آیفون، اندروید)
- تبلت‌ها

## 🛠️ نحوه استفاده

1. فایل‌ها را دانلود کنید
2. فایل `index.html` را در مرورگر باز کنید
3. برای تغییر منو، فایل‌های HTML و CSS را ویرایش کنید
