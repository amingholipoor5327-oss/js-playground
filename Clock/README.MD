# Digital Clock App ⏰

A sleek **digital clock** web application built with **HTML**, **CSS**, and **JavaScript**.  
It displays the current time (hours, minutes, seconds) and date in a modern, animated interface.

---

## Features

- Real-time digital clock with second-by-second updates
- Shows **hours, minutes, seconds**
- Displays **current date** (weekday, day, month, year)
- Blinking colon animation for a dynamic effect
- Modern glassmorphism design with blurred card background
- Fully **responsive**, works on desktop and mobile devices
- Easy to customize colors, fonts, and layout

---

## Technologies Used

- **HTML5** – Structure of the clock
- **CSS3** – Styling, animations, and responsive design
- **JavaScript (ES6)** – Logic for real-time updates and date formatting
