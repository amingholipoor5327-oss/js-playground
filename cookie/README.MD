# 📝 Simple Form with Local Storage

A simple and clean form project built with **HTML, CSS, and Vanilla JavaScript**.

This project stores user information (name & email) in the browser using **localStorage** and allows viewing the saved data later.

## ✨ Features

- Form validation
- Required fields check
- Save name & email
- Store data using localStorage
- View saved information
- Prevent page refresh on submit
- Clean modern UI

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM manipulation + localStorage)
