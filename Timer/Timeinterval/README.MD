# 🚦 Traffic Light Simulator

A simple Traffic Light simulator built with **HTML, CSS, and Vanilla JavaScript** to practice DOM manipulation and timers.

## ✨ Features
- 3 lights (Red, Yellow, Green)
- Automatic switching using `setInterval()`
- Start button
- Stop button
- Smooth transition effect
- Real traffic light behavior simulation

## 🛠 Technologies Used
- HTML5
- CSS3 (Flexbox + transitions)
- JavaScript (DOM + setInterval + clearInterval)
