# ⏳ setTimeout Mini Project

A simple JavaScript mini project to practice DOM manipulation and `setTimeout()`.

## 📌 Features
- Get user name from input
- Validate empty field
- Show confirmation before displaying
- Display message for 5 seconds
- Clear automatically using setTimeout
- Works with Enter key

## 🛠 Technologies
- HTML
- CSS
- JavaScript (Vanilla JS)

## 🚀 How it works
1. User enters their name
2. Clicks the button (or press Enter)
3. If input is empty → show error
4. If filled → show greeting message
5. After 5 seconds → message disappears automatically
