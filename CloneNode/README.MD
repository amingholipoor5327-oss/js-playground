# 🧩 Card Generator (CloneNode Project)

A simple and interactive **Card Generator** built with **HTML, CSS, and Vanilla JavaScript**.

This project demonstrates how to use `cloneNode()` to duplicate DOM elements dynamically and create reusable UI components.

## ✨ Features

- Add unlimited cards
- Clone card template using cloneNode(true)
- Dynamic content (name & description)
- Delete cards
- Clean modern UI
- No libraries (Pure JavaScript)

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM manipulation)

## 🚀 How it works

### 1️⃣ Enter information
User types:
- Name
- Description

### 2️⃣ Click "Add Card"
- A template card is cloned using `cloneNode(true)`
- Text is replaced with user data
- Card is added to the page

### 3️⃣ Delete
Each card has a delete button to remove it instantly
